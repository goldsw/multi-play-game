# 캐릭터 상태 머신

`CharacterStateMachine`은 행동 상태와 동시에 적용되는 효과를 제공함. 행동 우선순위는 탈락 → 기절 → 강제 이동 → 스킬 시전 → 걷기 → 대기 순서임. 감속·가속·투명화·화면 가림은 별도 플래그라 캐릭터가 걷거나 시전하는 동안에도 유지됨.

`EffectDefinition.CharacterFlags`에서 효과가 부여할 상태를 정의함. 호스트는 활성 효과의 플래그를 합쳐 동기화하며, 각 클라이언트는 `ActionChanged`와 `EffectsChanged`를 구독할 수 있음. 애니메이터를 연결하면 `CharacterAnimator`가 정수 파라미터 `CharacterAction`과 `CharacterEffects`를 갱신함.

기절과 탈락은 수평 속도를 0으로 처리함. 강제 이동은 효과 방향으로 이동하며, 이동 입력과 스킬·아이템 사용을 잠금. HUD는 같은 상태를 읽어 슬롯을 잠그고 어둡게 표시함. 아이템 기능에서 입력을 붙일 때 호스트에서도 `AllowsItemUse`를 확인함.

## 경기 규칙 연결

`MatchPlayerStateManager`는 2인 이상 경기 시작 시 술래를 한 명 고르고, 다른 참가자에게 새로 접촉하면 술래를 넘김. `SetTagger(player)`로 역할을 바꾸면 이전 술래의 함정이 제거됨. `Eliminate(player)`는 효과와 설치물을 정리하고 탈락 상태를 적용함.

로비에서 고양이·오리·강아지·토끼·다람쥐를 선택할 수 있음. 1인 개발 경기에서는 선택한 도망자 스킬로 테스트할 수 있음. 독버섯 폭발·승패 판정과 실제 애니메이션 클립은 별도 연결이 필요함.
