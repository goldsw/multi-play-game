## Commit Convention
프로그래머 분들은 이 커밋 메시지 규칙 따라주세요 (영문으로 작성할 시 첫 글자는 소문자로 해주세요. 한국어로 작성해도 됩니다.)
* `feat`: 새로운 기능 추가 (예: `feat: add Player EffectManager`)
* `fix`: 버그 수정 (예: `fix: physics engine AABB problem fix`)
* `refactor`: 코드 리팩토링 (기능 변화 없는 구조 개선) (예: `refactor: refactoring physics engine`)
* `docs`: 문서 수정 (README 등)
* `art / Asset`: 리소스(모델링, 사운드, UI 등) 추가 및 수정
* `chore`: 빌드 설정, 패키지 매니저 수정 등 기타 작업 (예: 'chore: player stats value change')
